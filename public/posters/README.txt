Drop poster images here (movies, series, gallery, designs).

Any file in this folder is served at /posters/<filename>
Example: posters/shawshank.jpg  ->  /posters/shawshank.jpg

Two ways to attach an image to a favourite item:
1. /jackal -> Beyond code -> the item -> Image field -> Upload button
   (goes to Supabase Storage, no repo changes needed)
2. Put the file here and paste /posters/<filename> into the item's
   Image field - works even without Supabase and ships with the repo.
